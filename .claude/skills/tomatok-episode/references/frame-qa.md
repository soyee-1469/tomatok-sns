# 현행 시작 프레임 QA — 12항목

SKILL.md §2의 필수 상세 검사. 승인 전 기준 이미지와 나란히 대조하고 컷 ID별 판정을 기록한다. 화면에 없는 항목은 해당 없음으로 표시한다.

1. 신체: 의도한 프레이밍인지, 팔다리 누락·추가·관절 오류가 없는지.
2. 가구 접촉: 앉는 위치·접촉·가림이 자연스럽고 관통하지 않는지.
3. 시선: 몸·얼굴·양쪽 눈동자 방향과 정렬, 상대 위치가 맞는지.
4. 손·소품 물리: 손가락·엄지·손목·사용하는 팔, 폰 앞뒤와 물건을 잡는 방식.
5. 얼굴: 마스터와 눈·코·입·머리선·안경 일치. 눈 벌어짐·비대칭·선명도도 확대 확인. 얼굴 크기·점수 경고는 직접 검증하고 불명확하면 보류.
6. 복장: 의상·신발·액세서리와 몸통 기준 이미지 일치.
7. 세트: 해당 회차·장면의 장소와 프레임 안 고정 요소 일치.
8. 조명: 시간대·창밖·광원·색감과 앞뒤 컷 연속성.
9. 비율·크롭: 9:16 목표, 샷 크기·여백·의도치 않은 신체 잘림 확인.
10. 소품 연속성: 컵·폰·담요·꽃·병의 개수·내용물·손 위치 유지.
11. 글자: 가짜 글자·워터마크·불필요한 자막 없음. 실제 UI는 별도 합성.
12. 배치·각도: 가구 방향·인물 자리·크기·높이·카메라 축·이동 전후 연결. 해당 장면 마스터 기준으로 검사하고 방 전체 설명을 모든 생성 프롬프트에 기계적으로 붙이지 않는다.

추가 연기 게이트: 시작 표정·감정·행동이 컷 의도에 맞는지 확인한다. QA 통과는 이후 영상 연기의 승인이 아니다.

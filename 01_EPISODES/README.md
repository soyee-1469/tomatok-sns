# EPISODES

한 편은 `EP###_TITLE` 폴더 하나다. EP002부터는 `EP001_FAMILY_GROUP_CHAT` 구조를 복제한다.

공통 얼굴, 장소, UI 스타일은 `00_MASTER_ASSETS`를 참조한다. 에피소드 폴더에는 그 편의 대본, 콘티, 컷, 생성물, 편집본만 둔다.

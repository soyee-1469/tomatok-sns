# EP01 v05 — 폰 화면 메시지 원문 (UI 합성용)

규칙 (UI_RULE, 방법서 4-5): 남자 폰에서는 **번역(한국어)이 위, 베트남어 원문이 아래**. 여자 폰에서는 자기가 보낸 말풍선은 번역 없음, 친척 메시지는 베트남어 그대로. 프로필은 실사 느낌 사진 또는 회색 사람 아이콘. 인원 수는 컷별 지정값과 맞춘다.
방 이름: `Gia đình 💕` (가족 💕). 남자 프로필명은 한국어 이름 그대로 노출.

## 등장 프로필 (베트남 남부식 호칭, 첫째가 Hai)
| 표시 이름 | 뜻 | 역할 |
|---|---|---|
| Dì Hai | 큰이모 | 환영 담당 |
| Dì Ba | 둘째 이모 | 외모 질문 |
| Dì Tư | 셋째 이모 | 면접관. 월급/집 질문 |
| Dì Năm | 넷째 이모 | 결혼식 재촉 |
| Cậu Sáu | 외삼촌 | 술 질문 |
| Mẹ | 엄마 | 마지막 입장 |

# EP01 SCRIPT v05 — "가족방이 안 멈춰요"

STATUS: DIALOGUE_REVIEW
작성: 2026-10-27, Claude Code (A안). 사용자 검토 대기.
러닝타임: 약 22~24초. 세로 9:16.
전제: 남자는 40초 전에 여자친구의 베트남 가족 토마톡 방에 초대됐다. 방 안의 모든 메시지는 양방향으로 번역돼 보이고, 친척들은 남자가 전부 읽는다는 것을 **알면서** 묻는다. 그래서 더 거침없다.

## 숏폼 구조
- 0초 콜드 오픈: 설명 없이 알림 폭주 한가운데서 시작
- 웃음 4단: 사람이 늘어난다 → 인사도 못 했는데 면접 → 말리니까 더 빨라진다 → 아직 엄마는 오지도 않았다
- 토마톡 설명 대사 0개. 번역된 메시지가 화면에 보이는 것만으로 기능이 전달된다
- 마지막 대사 후 1초 표정 정지, 폰은 계속 진동 → 처음 장면과 이어져 반복 재생

## 대본

### 0:00 콜드 오픈
남자 폰이 대리석 테이블 위에서 쉬지 않고 진동하며 조금씩 돈다.
화면 텍스트: **여자친구 가족방에 초대된 지 40초**

여 (태연하게 빨대를 빨며) 들어갔어?
남 …응.

### 0:03 사람이 늘어난다
남자 폰 화면. 베트남어 메시지 아래 한국어 번역이 줄줄이 올라온다.
방 인원 숫자가 대사 도중 23 → 27로 바뀐다.

남 지금… 사람이 늘고 있는데?
여 이모들이 다른 이모 초대하는 중이야.

### 0:08 다 읽는 걸 안다
남 내가 다 읽는 거 아시는 거지?
여 알지. 그래서 물어보는 거야.

### 0:10 인사도 못 했는데 면접
남자가 인사말을 한 글자씩 타이핑한다. 보내기 직전.
그 사이 새 메시지 14개. 번역: 월급은요? / 집은 있어요? / 어머니 성함이?

남 …나 인사 아직 못 보냈는데 면접이 시작됐어.
여 그건 셋째 이모야. 원래 그래.

### 0:14 말리면 더 빨라진다
여자 폰. 여자가 빠르게 메시지를 보낸다 (베트남어, 빨간 말풍선).
남자 폰. 번역 알림이 더 빨라진다.

남 뭐라고 보냈어?
여 쓸데없는 거 묻지 말라고.
남 …더 빨라졌는데?
여 그 말 하면 더 물어봐.

### 0:18 펀치라인
띵. 인원 32명. 입장 알림.

남 또 들어왔어.
여 (화면을 보고, 처음으로 멈칫) …어? 우리 엄마다.
남 엄마가 지금 들어와?
여 그동안은 다 이모였어.

남자 얼굴 1초 정지. 폰은 계속 진동.
END

## 연기 메모
- 여자는 끝까지 태연. 유일하게 표정이 바뀌는 순간이 "우리 엄마다".
- 남자는 대사를 웃기게 하지 않는다. 점점 작아지는 목소리와 정적으로 간다.
- 친척 메시지는 전부 남자에게 직접 묻는 2인칭. 뒷담화 톤 금지 (번역이 보이는 방이라 성립하지 않음).

## 자막
- 인물은 한국어로 말한다. 영어 자막 크게 + 한국어 자막 작게 (방법서 4-1).
- 폰 화면의 번역 텍스트는 자막이 아니라 UI 합성이므로 자막과 겹치지 않게 세이프존 안에서 배치.

# SKILL 04 — SCENE IMAGE GENERATION

## 목표
영상 생성에 사용할 안정적인 앵커 이미지를 만든다.

## 프롬프트 조립 순서
VISUAL BIBLE + CHARACTER BIBLE + ENVIRONMENT BIBLE + SHOT RULE + CURRENT SCENE

## 장면별 변동값
- 등장인물
- 장소
- 행동
- 감정
- shot type
- 시간대
- 필요한 소품

## 규칙
- 실제 TOMATOK UI는 가능하면 blank screen으로 생성 후 합성
- 로고는 실제 PNG 후합성 우선
- 영상에서 움직일 여백 확보
- 손/휴대폰/입 주변 형태를 특히 점검

## 출력
`EP###_SC##_anchor.png`

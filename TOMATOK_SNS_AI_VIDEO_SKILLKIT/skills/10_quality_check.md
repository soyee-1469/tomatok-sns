# SKILL 10 — QUALITY CHECK

## CHARACTER
- [ ] 같은 얼굴
- [ ] 나이대 일치
- [ ] 헤어 일치
- [ ] 체형 일치
- [ ] 의상 연속성

## HAND / BODY
- [ ] 손가락 이상 없음
- [ ] 관절 이상 없음
- [ ] 소품과 손 접촉 자연스러움

## ENVIRONMENT
- [ ] 가구 위치 일치
- [ ] 건축 구조 일치
- [ ] 시간대/조명 논리적

## CAMERA
- [ ] shot rule 준수
- [ ] eyeline 일치
- [ ] screen direction 일치

## VIDEO
- [ ] morphing 없음
- [ ] unnatural motion 없음
- [ ] phone/object 변형 없음

## VOICE
- [ ] 캐릭터 voice ID 일치
- [ ] 발음 자연스러움
- [ ] 감정 톤 일치

## LIPSYNC
- [ ] 입모양 동기화
- [ ] 턱/치아 왜곡 없음
- [ ] 얼굴 identity 유지

## BRAND
- [ ] TOMATOK 로고 정확
- [ ] UI 정확
- [ ] random text 없음

## COLOR
- [ ] 전후 컷 색온도 일치
- [ ] 피부색 자연스러움
- [ ] 레드 과포화 없음

FAIL 항목이 있으면 전체 에피소드가 아니라 해당 씬만 수정한다.

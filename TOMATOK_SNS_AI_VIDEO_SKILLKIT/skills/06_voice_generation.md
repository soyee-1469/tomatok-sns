# SKILL 06 — VOICE GENERATION

## 목표
캐릭터별 고정 음성을 생성한다.

## 절차
1. 대본 확정
2. 대사를 2~5초 단위로 분할
3. 캐릭터별 voice ID 적용
4. TTS 또는 실제 녹음 생성
5. WAV 저장
6. 길이/발음/감정 검수
7. 영상 길이 결정에 반영

## 권장 출력
- WAV
- 48kHz
- PCM

## 디렉션
- 자연스러운 대화체
- 광고 나레이션 톤 금지
- 문장 끝마다 과도한 억양 금지
- 캐릭터별 speaking speed 고정

## 파일명
`EP001_SC03_WIFE_001.wav`

## 중요
영상에 음성을 그냥 얹는 것과 립싱크는 별개다.
대사가 있는 얼굴 컷은 WAV를 립싱크 단계에 입력한다.
대사가 없는 reaction/insert 컷은 립싱크를 건너뛴다.

# SKILL 01 — CHARACTER GENERATION

## 목표
반복 사용 가능한 실사형 주인공을 확정한다.

## 입력
- 역할/나이대/문화 배경
- 성격
- 의상 방향
- visual_bible

## 출력
- 정면 무표정
- 정면 미소
- 45도 좌/우
- 측면
- 상반신
- 전신
- 감정 3~5종

## 생성 규칙
1. 먼저 정면 MASTER_FACE 후보를 만든다.
2. 사용자 승인 후 같은 얼굴로 각도를 확장한다.
3. 모든 파생 이미지에서 헤어/피부톤/얼굴 비율을 고정한다.
4. 동일 인물의 기준 시트에는 조명과 렌즈를 최대한 통일한다.
5. 너무 모델 같거나 광고 화보처럼 만들지 않는다.

## QC
- 얼굴 동일성
- 나이대 일치
- 헤어 일치
- 체형 일치
- 손/치아 이상 없음

# SKILL 02 — ENVIRONMENT GENERATION

## 목표
반복 사용 가능한 고정 세트를 만든다.

## 입력
- environment_bible
- visual_bible
- 필요한 장소 유형

## 출력
장소별 최소 4~5개 기준 뷰.

## 절차
1. 공간의 MASTER VIEW 생성
2. 좌/우/반대 방향 생성
3. 가구 위치와 건축 구조 비교
4. 일치하지 않으면 수정
5. reference 이름 부여

## 규칙
- 색감과 조명은 visual_bible 준수
- 랜덤 소품 추가 최소화
- 같은 공간에서 가구 배치 변경 금지
- 로고는 후합성 우선

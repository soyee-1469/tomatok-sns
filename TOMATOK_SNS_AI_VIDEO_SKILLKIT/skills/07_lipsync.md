# SKILL 07 — LIPSYNC

## 목표
기존 영상에 확정된 음성을 자연스럽게 맞춘다.

## 입력
VIDEO + CHARACTER VOICE WAV

## 권장 조건
- 얼굴 정면 또는 3/4
- 입이 충분히 보임
- 손/컵/휴대폰이 입을 가리지 않음
- 2~5초 짧은 대사
- 영상 속 표정과 음성 감정이 일치

## 절차
1. 영상과 WAV 길이 비교
2. 필요 시 앞뒤 무음/반응 여유 조정
3. lipsync 실행
4. 입/턱/치아/얼굴 정체성 검수
5. 실패 시 해당 씬만 재생성

## QC
- 음절 타이밍
- 턱 떨림 없음
- 치아 왜곡 없음
- 얼굴형 변화 없음
- 자연스러운 blink 유지

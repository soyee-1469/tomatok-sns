# ENVIRONMENT BIBLE

## 목표
장소도 캐릭터처럼 고정하여 에피소드가 바뀌어도 같은 세계관처럼 보이게 한다.

## MAIN SET — FAMILY HOME
- modern Korean apartment
- cream walls
- light wood floor
- beige sofa
- compact dining table
- indoor plants
- soft curtains
- large window
- practical household objects
- lived-in but uncluttered
- subtle TOMATOK red accent in one or two small props

### 필수 레퍼런스
- livingroom_front
- livingroom_left
- livingroom_right
- kitchen_view
- dining_view

## OPTIONAL SETS
### SCHOOL / COMMUNITY CENTER
- 밝고 실용적
- 과도하게 고급스럽지 않음
- 실제 생활 서비스 공간 느낌

### TOMATOK EVENT / BOOTH
- white + deep navy structure
- small TOMATOK red accents
- actual logo composited later when possible
- bright event lighting

### OFFICE
- warm daylight
- clean contemporary workspace
- plants / light wood / neutral colors

## 연속성 규칙
- 같은 장소의 문/창/소파/식탁 위치를 임의 변경하지 않는다.
- 카메라 방향이 달라도 공간 구조는 일치해야 한다.
- 낮/밤은 조명만 변하고 세트 구조는 유지한다.

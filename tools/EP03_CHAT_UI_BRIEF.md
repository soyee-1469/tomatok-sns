## 화면 규칙

- `00_MASTER_ASSETS/04_UI/UI_RULE.md`와 실제 스크린샷을 따른다. 헤더에 인원수 새로 넣지 않는다.
- 준호 폰 한국어 뷰: 상대 외국어는 흰 한국어 번역 위 + 회색 원문 아래, 상대 한국어는 흰 원문만. 준호 본인만 연분홍.
- 리아 영어, 하오 중국어, 미유 일본어, 수만 네팔어. 원문은 번역 초안으로 분리하고 검수 전 최종 처리하지 않는다. 국기로 언어를 자동 결정하지 않는다.
- 채팅 대사와 순서는 각본 §4를 따른다. 여섯 상태는 각본 §5 참고.
- 할머니는 공지 작성자이자 대화 참여자. 프로필과 「오는 길에 뛰지 마라.」가 보여야 한다.
- 프로필 목록과 메시지 상태를 브라우저에서 확인할 수 있게 HTML 미리보기. 390px 폭에서 가로 넘침 없게.
- 컷별로 읽을 수 있는 메시지만 표시. 전체 대화를 한 장에 작게 욱여넣지 않는다.
- 폰 목업은 공용 `00_MASTER_ASSETS/04_UI/MOCKUP/phone_mockup.py` 사용. 독자 폰 외곽 디자인 금지.
- 이미지·영상은 Git에 올리지 않는다. 데이터·코드·문서만 올리고 결과는 로컬 경로 보고.

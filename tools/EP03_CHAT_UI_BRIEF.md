## 화면 규칙

- 사용자 수정(2026-11-12): 한국어가 아직 서툰 입주민들이 같은 거실에서도 각자 편한 언어로 토마톡을 적극 활용한다. 메뉴 제안과 협의는 단톡 메시지로 표현한다. 대면 대화로 바꾸자는 대사·연출은 사용하지 않는다.
- 메뉴 상태 최신 순서: 하오 치킨 사진·제안 → 리아 튀긴 것 제외 / 미유 닭 제외 → 하오 피자 사진·제안 → 리아 점심 빵 / 미유 밥 선호 → 하오 「먹고 싶은 걸 하나씩 써 주세요」 → 리아 「둘이 정해. 나는 진짜 아무거나 괜찮아.」. 이후 소고기 합의·철회도 채팅. 이전 초안의 「왜 화났어?」는 삭제.
- `00_MASTER_ASSETS/04_UI/UI_RULE.md`와 실제 스크린샷을 따른다. 헤더에 인원수 새로 넣지 않는다.
- 준호 폰 한국어 뷰: 상대 외국어는 흰 한국어 번역 위 + 회색 원문 아래, 상대 한국어는 흰 원문만. 준호 본인만 연분홍.
- 리아 영어, 하오 중국어, 미유 일본어, 수만 네팔어. 원문은 번역 초안으로 분리하고 검수 전 최종 처리하지 않는다. 국기로 언어를 자동 결정하지 않는다.
- 채팅 대사와 순서는 각본 §4를 따른다. 여섯 상태는 각본 §5 참고.
- 할머니는 공지 작성자이자 대화 참여자다. 프로필과 공지에 반드시 포함한다. 최신 결말에서는 뒤늦게 소고기를 양손 가득 들고 도착한다. 도착 전 채팅에 구매 사실을 미리 공개하지 않는다.
- 최신 후반 상태: 수만 참석 확답 → 리아 가볍게 / 미유 김밥 → 하오 김밥 선택 → 수만 도착 후 「내가 온다고 해서?」 → 할머니 소고기 등장(실사 장면) → 식사 중 수만 「나 오늘 오길 잘했네.」 / 리아 「할머니 잘 먹겠습니다」. 이전 「기다릴게요」·「오는 길에 뛰지 마라」·「다음에 하오 없는 날」·「나 이제 안 빠져요」는 사용하지 않는다.
- 프로필 목록과 메시지 상태를 브라우저에서 확인할 수 있게 HTML 미리보기. 390px 폭에서 가로 넘침 없게.
- 컷별로 읽을 수 있는 메시지만 표시. 전체 대화를 한 장에 작게 욱여넣지 않는다.
- 폰 목업은 공용 `00_MASTER_ASSETS/04_UI/MOCKUP/phone_mockup.py` 사용. 독자 폰 외곽 디자인 금지.
- 이미지·영상은 Git에 올리지 않는다. 데이터·코드·문서만 올리고 결과는 로컬 경로 보고.

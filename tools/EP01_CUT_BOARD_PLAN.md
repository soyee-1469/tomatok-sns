# 1화 기존 자료 정리 — 컷별 비교 보드

2026-11-12 사용자 지시. 구현은 Cursor, 결과 검수는 Codex. 새 콘티 생성은 그록봇 담당.
이미 있는 각본·콘티·이미지·영상만 정리한다. 이미지·영상 생성 API 호출 금지.

## 화면 구성

회차 작업실 `board_web/series.html#EP01/images`의 단순 이미지 갤러리를 컷별 비교 화면으로 확장한다.

각 컷은 아래 구조로 한 묶음:

1. 컷 번호 / 인물 / 대사. 바로 아래 지문(상황·동작), 필요하면 접어서 표시.
2. 나란히 세 칸: **콘티 → 이미지(대사 자막 미리보기) → 영상**.
3. 콘티나 영상이 없으면 「미연결」 또는 「영상 없음」 표시. 자동으로 생성하거나 승인 처리하지 않는다.
4. 영상이 여러 테이크면 드롭다운으로 비교. 기본값은 실제 편집 데이터에서 지정한 클립. 최신 번호를 무조건 기본값으로 삼지 않는다.
5. 자막 표시/숨김. 이미지 위 자막은 검토용 HTML 오버레이이며 원본에 굽지 않는다. 영상에 대사를 함께 보여 줄 때도 검토용 전체 대사임을 구분하고 싱크 완료 자막처럼 표시하지 않는다.
6. 휴대폰에서는 세 칸을 컷 단위로 세로 배치. 원본 크게 보기, 영상 controls·playsinline·preload=metadata. 자동 재생 금지.

최상단에는 연결된 컷·이미지·영상 수와 간단한 필터(전체 / 영상 있음 / 영상 없음 / 콘티 미연결). 과거 교체본은 기본 목록과 섞지 않고 별도 접힘 영역.
기존 이야기·3화 단톡 UI 링크·최종 제작 탭 보존. 화면에서 생성 서비스는 호출하지 않는다.

## 기준 데이터와 확인된 내용

- 현재 1화 편집 데이터: `01_EPISODES/EP01R/edit/v06/animatic_E1_v062.json`.
- 확인 시 45행, skip 20·21·29를 제외한 42개 활성 컷. 원본 JSON은 읽기 전용. 실행 시 다시 계산하고 개수를 코드에 고정하지 않는다.
- `n`, `who`, `line`, `dir_override` 우선(없으면 `situation`·`action`), `emotion`, `src`, `frame`, `kind`, `clip`, `clip_note` 사용.
- `kind=ui`의 `src`는 mp4일 수 있다. 일반 인물 이미지인 것처럼 처리하지 않는다. 읽을 수 있는 UI 미리보기와 기존 UI 영상으로 구분.
- 대사 없는 컷과 괄호로 된 연출 메모는 음성 대사 자막으로 얹지 않는다. 화자·문맥 확인.
- `src`가 현재 이미지, `clip`이 현재 지정된 영상. 파일 존재를 확인하고 둘을 같은 컷에 연결한다.
- 컷3 예: 이미지 `frames/v08/S_ria_island_act2_cu.png`, 선택 클립 `video/v08/E1_03/EP01R_E1_03_kling3_take01.mp4`. 같은 폴더에 take04·05·06도 있지만 편집 JSON 지정은 take01이다. 새 번호를 승인본으로 오인하지 않는다.
- 추가 테이크: `01_EPISODES/EP01R/video/v08/E1_<컷번호>/`에서 엄격한 정상 파일명 `*_take<숫자>.mp4`만 검색. `_old`, `_old2`, contact PNG 등은 기본 후보에서 제외.

## 콘티 연결의 주의점

- 기존 콘티 폴더: `01_EPISODES/EP01R/frames/v08/STORYBOARD/`.
- `cuts_island.json`은 스틸 키 → `sketch`와 `frame_ref` 관계의 근거다.
- 현재 JSON의 `frame`, `frame_group`, `frame_prev`, `frame_old`와 실제 생성 메타데이터의 참조 경로 등을 확인해 근거 있는 연결만 한다.
- **콘티 파일의 C번호와 현재 컷 번호가 같다는 이유만으로 연결 금지.** 옛 콘티는 컷 7~15 등 구버전이고 컷 삽입·순서 변경이 있었다.
- `prompts_E1/INDEX.md` 역시 옛 44컷 기반으로 현재 45행과 다르다. 확인 없이 그대로 적용 금지.
- 과거 구성의 참고 연결은 「이전 구도 참고」로 구분. 확실하지 않은 것은 미연결로 남겨 사용자에게 확인할 목록 작성.
- 결과 근거를 `tools/ep01_cut_asset_map.json`에 저장: 컷 번호, 현재 이미지·선택 클립, 테이크 목록, 콘티 경로, 매핑 근거·미연결 사유. 상대경로 사용. 원본 파일 이동·변경 금지.

## 구현 범위

허용: `tools/build_series_board.py`, `tools/series_board.html`, 새 `tools/series_cut_assets.py`(필요시), 새 `tools/ep01_cut_asset_map.json`, 새 `tools/EP01_CUT_BOARD_REPORT.md`. 로컬 산출은 `board_web/` 하위.
원본 각본·애니매틱 JSON·이미지·영상·기존 DB 판정은 읽기 전용. 원본 파일명 변경·삭제 금지.
미리보기 파일명은 소스 상대경로 기반으로 유일하게 만들어 동명이인 덮어쓰기 방지. 바이너리는 Git 제외. 용량 큰 클립을 불필요하게 중복 복사하지 않는다.

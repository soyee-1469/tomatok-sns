# 회차 작업실

생성: `python3 tools/build_series_board.py`

미리보기: `python3 board_web/serve.py` 실행 후 http://127.0.0.1:8765/series.html

첫 화면에서 회차를 고르고 이야기 / 콘티·기준 이미지 / 최종 제작으로 이동한다.
각본과 콘티는 어느 쪽부터 시작해도 된다. 이미지 준비는 GPT 이미지가 기본이며 영상은 최종 확정과 사용자 명시 지시 이후 힉스필드에서 진행한다.
현재 화면은 기존 자료를 읽는 검토용이며 승인·편집 내용을 저장하는 기능이나 생성 서비스 연결은 없다.

원문과 기존 보드는 보존한다. 생성기는 각본 사본과 콘티 미리보기를 board_web에 만들며, 원문 수정 후 다시 실행한다.
회차 추가와 원문 경로는 tools/build_series_board.py의 EPISODES에서 관리한다.
2화는 EP02_SCRIPT_v08.md를 사용한다. 기존 EP02/status.json은 다른 제목의 옛 기획이므로 덮어쓰지 않았다.
1화 기존 상태 파일도 과거 제작 상태이므로 새 화면에서 자동 승인으로 해석하지 않는다.

현재 연결: 1화 각본·콘티 12장, 2화 USB 장면 반영 각본·기존 콘티 보드 4장, 3화 「오늘 못 와?」 공동 저녁 각본 v03. 2화 기존 콘티는 USB 변경 전 자료이며 재검토 필요.
다음 작업: 화면 검토, 2화 콘티별 기준 이미지 준비, 3화 각본 검토. 단톡방 UI는 CURSOR_TASKS 작업 28, 상세 기준은 tools/EP03_CHAT_UI_BRIEF.md. 영상 생성 권한은 부여되지 않았다.

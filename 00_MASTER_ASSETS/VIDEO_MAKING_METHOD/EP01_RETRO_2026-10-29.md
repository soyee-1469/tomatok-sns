## 저장해 둘 스킬·도구 (EP02부터 그대로 사용)
- `01_EPISODES/EP01/tools/hf_gen.py` — Higgsfield CLI 1회 생성 + 대기 + _status.json + mp4 curl 다운로드(urllib은 403)
- `01_EPISODES/EP01/tools/transcribe.py` — faster-whisper small. 생성 직후 대사·언어 검사(말레이어/영어 환각, 바뀐 대사 적발)
- `01_EPISODES/EP01/tools/remove_spot.py` — 뺨 점 같은 환각 자국을 템플릿 추적 + 인페인팅으로 제거
- `01_EPISODES/EP01/ui/real/render_ui_v2.py` — 실제 토마톡 레이아웃 채팅 UI(프로필 사진, 연속 스크롤, 날짜 알약 없음), 잠금화면
- `01_EPISODES/EP01/ui/real/still_anim.py` — 스틸 위 UI 합성: white=250 폴리곤 검출 또는 quad 직접 지정, corner=95 둥근 모서리, occl=display(손가락·손톱 보존), fit=stretch, grow_top/grow_bot, jitter
- `01_EPISODES/EP01/tools/subtitle_style.py` + `subtitles_pass.py` — B안 자막(흰 글자+반투명 바, 72%), whisper 단어 시간으로 타이밍, 컷 경계 클램프, 상황 자막 y 지정, 대사표에 감정 메모
- `00_MASTER_ASSETS/08_OUTRO/render_outro.py` — 공통 아웃트로(로고 4x, 부제 "언어가 달라도 대화는 바로바로")
- `edit/assemble_v24e.py` 형식 — picks = (컷, 파일, 길이, 음소거[, 시작오프셋[, 오디오필터[, 비디오필터]]]), 띠링 타임라인, 앰비언스 베드. 음소거 인서트는 anullsrc
- BGM 믹스 — volume 0.16 + sidechaincompress(threshold 0.06, ratio 6, attack 40, release 500), 1s 페이드인, 끝 2.5s 페이드아웃
- 매치컷 레시피 — `ffmpeg -sseof -0.05`로 대사 컷 마지막 프레임 추출 → 동작 컷 시작 이미지. 컷 경계에서 크롭/줌 동일하게
- 크레딧 감사 — `higgsfield account transactions --size 100 --cursor N --json`

## EP02 표준 절차 (목표 ≤200 크레딧, 반나절)
1. 대본 확정: 모든 줄에 (감정, 말투, 끝음). 대사 컷 ≤3초, 한 컷 한 사람 한 줄
2. 스틸: Nano Banana Pro(CLI 2크레딧/장) 또는 웹 무제한 확인 후 웹
3. 영상: std, 컷당 1테이크 → `transcribe.py` → 실패 컷만 1회 추가. 동작 컷은 마지막 프레임에서
4. 조립: assemble picks → 띠링/앰비언스 → 픽처락 승인
5. 마무리: UI 인서트(≤2) → 자막 B안 → BGM 덕킹 → 아웃트로 → 세이프존 → 내보내기
6. 모든 생성 전 비용 보고 후 승인

# UI RULE

토마톡 UI는 영상 모델이 그리지 않는다. 이 폴더의 실제 화면을 컷 길이에 맞춰 후합성한다.

## 노출
- 기능 설명 자막 없음
- 한 컷에서 1~3초
- 등장인물이 원래 쓰는 메신저처럼 보이게 한다
- 로고와 문구는 제공 에셋을 쓰고, 글자를 생성하지 않는다

## 화면 역할
- `TOMATOK_FAMILY_ROOM_KR`: 한국어 가족방
- `TOMATOK_FAMILY_ROOM_VN`: 베트남어 가족방
- `TOMATOK_TRANSLATION`: 원문과 번역이 함께 보이는 화면
- `TOMATOK_GROUP_CHAT`: 일반 단톡방
- `TOMATOK_PHOTO_SHARE`: 사진 공유

## EP001
- 남주 화면: 베트남어 원문 + 한국어 번역
- 여주 화면: 한국어 메시지 + 베트남어 번역

## 실제 토마톡 채팅 화면 (2026-10-29 사용자 제공, REAL_SCREENS/)
- `TOMATOK_REAL_KR_VIEW_우리가족.png`: 한국 사용자 폰. 상대(베트남 할머니 🇻🇳) 메시지 = 흰 말풍선(한국어 번역) 위 + 회색 말풍선(베트남어 원문) 아래, 시각은 회색 말풍선 오른쪽 아래. 내 메시지 = 연분홍 말풍선(#f9dcdc 계열), 번역 없음, 시각 왼쪽.
- `TOMATOK_REAL_VN_VIEW_Gia_dinh_minh.png`: 베트남 사용자 폰. 같은 대화가 베트남어 기준으로 뒤집혀 보임(상대 한국어 메시지 = 흰 베트남어 번역 위 + 회색 한국어 원문 아래).
- 공통: 헤더 = 뒤로가기 ‹ / 방 이름 가운데 / 검색 / 메뉴. 날짜 알약(회색) "2025-08-06 수요일". 프로필은 실사 사진 원형 + 이름 + 국기 이모지. 입력창 = ⊕ / "메시지를 입력하세요." + ☺ / 종이비행기 버튼. 배경 #f2eeeb. 인원수 표시는 헤더에 없음(방 이름만).
- 모든 UI 렌더는 이 두 장을 기준으로 한다. 이전 렌더(BASE_CHAT_ROOM 기반, 빨간 내 말풍선)는 폐기.
- `TOMATOK_REAL_NOTIFICATION_BANNER.png`: 실제 알림 배너(2026-10-29 사용자 제공). 흰 둥근 카드, 왼쪽 토마톡 앱 아이콘(빨간 토마토 말풍선), '오후 2:31' / '✉️ 새 메시지 도착' / '새 메시지가 도착했어요. 지금 확인해보세요!'. C0 잠금화면 알림은 이 배너를 그대로 쌓는다. 앱 아이콘은 `04_UI/TOMATOK_APP_ICON_from_banner.png`로 잘라둠.

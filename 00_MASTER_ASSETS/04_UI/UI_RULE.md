# UI RULE

토마톡 UI는 영상 모델이 그리지 않는다. 이 폴더의 실제 화면을 컷 길이에 맞춰 후합성한다.

## 노출
- 기능 설명 자막 없음
- 한 컷에서 1~3초
- 등장인물이 원래 쓰는 메신저처럼 보이게 한다
- 로고와 문구는 제공 에셋을 쓰고, 글자를 생성하지 않는다

## 화면 역할
- `TOMATOK_FAMILY_ROOM_KR`: 한국어 가족방
- `TOMATOK_FAMILY_ROOM_VN`: 베트남어 가족방
- `TOMATOK_TRANSLATION`: 원문과 번역이 함께 보이는 화면
- `TOMATOK_GROUP_CHAT`: 일반 단톡방
- `TOMATOK_PHOTO_SHARE`: 사진 공유

## EP001
- 남주 화면: 베트남어 원문 + 한국어 번역
- 여주 화면: 한국어 메시지 + 베트남어 번역

## 언어 뷰 규칙 — 폰 주인의 언어로만 보인다 (2026-11-05 사용자 지시, 같은 날 2차 수정)
토마톡은 자동 번역이라 **같은 대화가 폰마다 다르게 보인다.** 한 컷의 UI는 반드시 "누구 폰인가"를 먼저 정하고, 그 사람의 언어로 렌더한다.

말풍선 형식 (REAL_SCREENS 목업 그대로):
- **보낸 메시지** = 분홍 말풍선, 내 언어 원문만. 번역 없음.
- **받은 메시지** = 흰 말풍선(내 언어 번역) 위 + 회색 말풍선(상대 원문) 아래. **예외 없음.** 상대가 나와 같은 언어로 보냈어도 흰·회색 두 줄을 붙인다(영어끼리면 흰 영어 + 회색 영어). 2026-11-05 사용자 지시. 이전의 "같은 언어면 원문만" 규칙(Emily 사례)은 폐기.

리아 가족 언어 설정 (2026-11-05 사용자 지시): 리아는 혼혈이라 **가족방 언어가 둘**이다. 아빠 쪽은 영어, 엄마 쪽은 타갈로그어. 구성은 `WORLD_PLANNING/FAMILY_ROOM_v02.md`.

| 보낸 사람 → 보는 폰 | 준호 폰 (한국어 뷰) | 리아 폰 (영어 뷰) |
|---|---|---|
| 준호 | 분홍, **한국어만** | 흰 영어 번역 + 회색 한국어 원문 |
| 리아 | 흰 한국어 번역 + 회색 영어 원문 | 분홍, **영어만** |
| 아빠 쪽 가족 (영어) | 흰 한국어 번역 + 회색 영어 원문 | 흰 영어 + 회색 영어 (같은 글 두 번) |
| 엄마 쪽 가족 (타갈로그어) | 흰 한국어 번역 + 회색 타갈로그어 원문 | 흰 영어 번역 + 회색 타갈로그어 원문 |
| 순덕·하영 (한국어) | 흰 한국어 + 회색 한국어 (같은 글 두 번) | 흰 영어 번역 + 회색 한국어 원문 |

- 리아 폰의 앱 언어는 영어(헤더·입력창 "Type a message"·시각까지 영어). 준호 폰은 한국어.
- **준호는 자기 말이 영어로 어떻게 갔는지 자기 폰에서는 못 본다.** 드라마의 핵심 틈(2화: 번역이 존댓말로 바꿔 보낸다).
- 21명 방(「Villanueva Fam 🤫 (21)」)은 리아 폰에만 있으므로 항상 영어 뷰. 22명 방은 두 폰 다 나올 수 있다.
- 렌더 파일 이름에 뷰를 적는다: `..._KR_VIEW.png`(준호) / `..._EN_VIEW.png`(리아). 한 장면에서 두 폰을 번갈아 보여 줄 때 같은 메시지가 두 언어로 두 번 렌더된다.

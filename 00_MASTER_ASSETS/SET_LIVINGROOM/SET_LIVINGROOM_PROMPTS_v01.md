## (1) Space Layout — 어디에 무엇

1층은 하나의 열린 L자 공간입니다. 프렌즈 아파트처럼 기본 카메라는 **현관 벽(남쪽)에 서서 북쪽 큰 창을 바라보는** 위치이고, 아래 좌/우는 그 기준입니다.

| Zone | 위치 (기본 카메라 기준) | 시그니처 소품 (매회 반복) |
|---|---|---|
| **A. 큰 창 + 창가 벤치** | 정면 안쪽 벽 중앙 | 아치형 검은 스틸 프레임 창 1개(연남동 개조주택 느낌), 낮은 빌트인 창가 벤치 + 베이지 린넨 쿠션, 왼쪽 몬스테라 화분, 창틀 위 네팔 기도 깃발 한 줄, 상단 따뜻한 전구줄. 아침 빛은 여기서 들어온다. |
| **B. 소파 존 (히어로 스팟)** | 방 중앙, 소파가 카메라를 보고 창을 등짐 | **카라멜 탄 코듀로이 3인 소파**("토마톡 소파"), 오른쪽 끝 **머스타드 1인 암체어** 비스듬히, 라이트 오크 원형 커피테이블 + **토마토 레드 세라믹 트레이**, 크림 주트 러그. 소파 뒤 낮은 오크 콘솔 + 빈티지 라디오 + 단체사진 액자. |
| **C. 주방 아일랜드 + 오픈 키친** | 방 오른쪽 | **화이트 마블 상판 + 오크 베이스 아일랜드, 검은 메탈 바스툴 3개**(거실 쪽을 향함). 뒤로 베이지 무광 수납장, 오픈 스파이스 선반(네팔 구리 향신료 통, 필리핀 바나나 케첩, 일본 간장, 한국 고추장통), 구리 냄비 행잉 레일, 소형 에스프레소 머신, 다국어 마그넷·메모 붙은 냉장고. 아일랜드 위 펜던트 램프 3개. |
| **D. 현관 + 계단** | 방 왼쪽 | 회색 스틸 현관문(불투명 유리 패널), **제각각인 신발 7~8켤레로 넘치는 신발장**, 믹스 재킷 걸린 코트 훅 벽, 왼쪽 벽을 따라 **2층으로 오르는 오크 오픈 계단 + 검은 난간**, 전신 거울, 4개 언어로 쓴 작은 "하우스 룰/장보기" 칠판. |
| **E. 다이닝 누크** | 소파와 창 사이, 약간 왼쪽 | 4인 라이트 오크 식탁 + 짝이 안 맞는 의자, 위에 종이등 펜던트. |
| **F. 세계의 벽** | 주방 쪽 오른쪽 벽 상단, 와이드에서 보임 | 갤러리 월: 필리핀 지프니 프린트, 카트만두 산 사진, 도쿄 네온 엽서, 서울 지하철 노선도, "WELCOME / MABUHAY / ようこそ / नमस्ते / 환영합니다" 레터보드. |

**팔레트:** 웜 베이지 벽, 라이트 오크, 크림 패브릭, 카라멜 소파, 머스타드 포인트, 토마토 레드 마이크로 포인트(트레이·머그 1·쿠션 1), 무광 블랙 메탈 라인(창틀·난간·스툴). 바닥은 라이트 오크 헤링본.

**조명 규칙:** 큰 창(북쪽)에서 들어오는 부드러운 아침 햇살 + 펜던트 웜 필, 강한 그림자 없음, 약 4500K, 전부 선명하고 깨끗하게.

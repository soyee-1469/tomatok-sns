# 연남동 3층집 4화 「조금만 주세요」 — 각본 v02

## 0. 로그라인

반찬통을 돌려받으러 온 순덕은 수만의 네팔 음식에 눈을 반짝이고, 수만은 순덕의 무말랭이를 먹을 때마다 밥그릇을 당긴다. 서로의 조리법이 궁금한 두 사람은 토마톡 번역을 번갈아 누르며 이야기를 나누고, 결국 “조금만” 나눠 달라면서 똑같이 큰 통을 꺼낸다.

## 1. 상황

- 주말 점심 무렵, 1층 공용 거실 뒤 식탁. 수만이 쉬는 날 자기 점심을 먹으려 한다. 앞치마 없음. 다른 사람들 식사를 준비하는 상황이 아니다.
- 식탁에는 수만의 밥, 순덕이 준 무말랭이 작은 접시, 수만이 자기 방식으로 만든 네팔 음식 아차르 작은 접시가 있다. 보관용 큰 통 두 개는 식탁 옆에 닫아 둔다. 실제 조리법을 설명하는 레시피 영상은 아니다.
- 순덕은 단톡에 빈 반찬통 회수 요청을 보내고 온다. 수만은 반찬을 다 먹은 통을 깨끗이 씻어 포개 두었다. 다른 용도로 쓰지 않았다.
- 주인공은 순덕·수만 둘. 리아는 초반에 빈 통 위치를 알려 주고 자리를 비운다. 마지막까지 옆에서 통역해 주지 않는다.
- 수만은 대면에서 네팔어로 중얼거리거나 손짓한다(2026-11-13). 한국어 장문·설명은 하지 않는다. 재료·조리 이야기는 토마톡 번역. 「감사합니다」처럼 짧은 인사만 예외. 순덕은 네팔어를 못한다. 상세: `05_STYLE/suman_language_rule.md`.
- 토마톡 번역 화면에서 각자 음성 입력을 누르고 자기 언어로 말한 뒤 상대 언어 번역을 확인한다. 제품의 버튼 명칭·위치·음성 재생 여부는 실제 UI 확인 후 확정. 아래 네팔어 발화는 독자가 이해할 한국어 뜻이며 원문은 제작 전 검수한다.
- 도입의 공동 단톡 공지와 식탁의 번역 대화는 다른 화면 역할이다. 근거리의 짧은 인사는 직접 말하고, 긴 요리 이야기를 번역으로 잇는다.
- 순덕은 억척스럽지만 먹이는 데는 넉넉하다. 수만 음식에도 순수하게 호기심을 보인다. 두 음식의 우열·국적별 맛 평가·번역 오류 개그는 쓰지 않는다.

## 2. 인물 카드

| 인물 | 원하는 것 | 막히는 것 | 시작 → 끝 |
|---|---|---|---|
| 순덕 | 통을 챙겨 가기, 처음 보는 음식의 맛과 만드는 법 알기 | 이름과 조리 설명을 알아듣기 어려움 | 통 회수 → 호기심 → 요리하는 사람끼리 공감 → 넉넉한 음식 교환 |
| 수만 | 자기 점심을 먹고 할머니에게 감사하기 | 고마움과 궁금한 조리법을 한국어로 길게 말하기 어려움 | 맛있게 식사 → 자기 음식 소개에 신남 → 할머니 방식에 웃음 → 서로 다음 반찬 약속 |
| 리아 | 할머니에게 빈 통 위치 안내 | 없음 | 둘이 대화할 자리를 만들어 주고 퇴장 |

| 1 | 빈 통 요청을 보고 수만이 씻은 통을 준비 | 평온 → 반가움 | 통을 쌓고 할머니 반찬으로 점심 | 할머니 반찬은 아껴 먹을 만큼 인기 |
| 2 | 순덕이 아차르를 발견 | 업무 → 호기심 | 가던 손을 멈추고 식탁에 앉음 | 할머니는 요리 자체에 관심이 많다 |
| 3 | 수만이 말로 설명하다 토마톡 번역을 꺼냄 | 답답함 → 신남 | 음성 입력을 눌러 이름·소개 전달 | 두 사람이 직접 소통할 수 있다 |

| 5 | 분량을 묻자 둘 다 손으로 양을 보임 | 진지함 → 알아보는 웃음 | 이만큼, 적당히, 서로의 손을 봄 | 둘 다 자기 감각으로 요리하는 사람 |
| 6 | 조금만 달라면서 큰 통을 꺼냄 | 아쉬움 → 들킴 → 웃음 | 서로 같은 크기의 통을 내밈 | 남이 해 준 음식 앞에서는 둘이 똑같다 |
| 7 | 빈 통이 다시 음식으로 채워짐 | 회수 → 교환 | 상대 몫을 넉넉히 담아 닫음 | 이 집의 반찬통은 음식을 오가게 한다 |

## 4. 씬 본문

### 1. 통은 씻어 놨어요

점심 무렵. 수만이 식탁에 혼자 앉아 있다. 무말랭이 한 조각을 먹고, 밥 한 숟갈. 씹다가 반찬을 한 조각 더 집는다.

폰 알림이 한 번 울린다. 토마톡 「연남동 3층집 🏠」.

**단톡 / 순덕 할머니:** 『빈 반찬통 있으면 내놔라. 반찬 담을 통이 없다.』

수만이 번역된 메시지를 읽는다. 옆에 씻어 둔 통들을 가지런히 포갠다. 폰을 내려놓고 무말랭이를 한 조각 더 먹는다.

잠시 후. 순덕이 거실에 이미 와 있다. 리아가 식탁 쪽을 가리킨다.

**리아** (밝게 안내, 통을 가리키며, 끝↓): “할머니, 수만이 씻어 놨어요.”

리아가 자기 컵을 챙겨 자리를 비운다. 순덕이 포개진 통을 집는다. 안쪽까지 깨끗하다.

**순덕** (흡족, 통을 살피며, 끝↑): “잘 먹었어?”

수만이 입 안의 밥을 삼키고 바로 고개를 끄덕인다. 엄지를 치켜 올려 보인다. 말은 없다.

수만이 무말랭이를 집는다. 순덕이 보는 앞에서 밥그릇을 조금 더 자기 쪽으로 당긴다. 순덕의 입꼬리가 올라간다.

### 2. 그건 뭐야?

통을 장바구니에 넣으려던 순덕의 시선이 다른 접시에 멈춘다. 처음 보는 아차르다.

**순덕** (호기심, 접시를 가리키며, 끝↑): “그건 뭐야?”

수만이 반가워한다. 접시를 조금 밀어 보인다.

수만이 반가워하며 접시를 조금 밀어 보인다. 접시와 자기를 번갈아 가리키며 네팔어로 중얼거린다. (뜻: 아차르. 네팔 음식. 내가 만들었어요.)

순덕이 음식을 유심히 본다. 가까이에서 향도 맡는다.

**순덕** (더 궁금해짐, 접시에 몸을 기울이며, 끝↑): “이건 뭘 넣은 거야?”

수만이 재료를 설명하려다 한국어 단어가 막힌다. 손으로 모양을 그려 보다가, 자기 폰을 집는다.

토마톡 번역 화면. 수만이 음성 입력을 누르고 네팔어로 말한다. 순덕은 폰을 들여다본다.

**수만 — 네팔어 발화의 뜻:** “제가 집에서 만들어 먹는 아차르예요. 한번 드셔 보실래요?”

**번역 화면 / 한국어:** 『제가 집에서 만들어 먹는 아차르예요. 한번 드셔 보실래요?』

순덕이 화면을 읽고 수만을 본다. 기다렸다는 듯 고개를 끄덕인다.

### 3. 말보다 먼저 아는 표정

수만이 깨끗한 포크로 한 조각을 새 접시에 담아 드린다. 순덕이 맛본다.

수만의 시선이 할머니 얼굴에 붙는다. 순덕은 천천히 씹는다. 한 번 더 씹고, 접시를 내려다본다.

**순덕** (뜻밖에 마음에 들어, 눈썹을 들며, 끝↓): “어. 이거 맛있네.”

수만 얼굴이 환해진다. 할머니가 접시를 조금 가까이 당긴다.

순덕이 수만 폰을 가리킨다. 수만이 할머니가 쓸 수 있게 식탁 가운데 둔다.

순덕이 음성 입력을 누르고 또박또박 말한다. 처음엔 조금 크게 시작했다가 수만이 웃자 평소 목소리로 돌아온다.

**순덕** (요리하는 사람의 궁금증, 음식을 가리키며, 끝↑): “이 향은 뭘 넣어서 나는 거야?”

수만이 네팔어 번역을 읽는다. 아까 손으로만 그리던 것과 달리 곧바로 알아듣는다. 신나서 입력을 누른다.

**수만 — 네팔어 발화의 뜻:** “제가 쓰는 향신료가 있어요. 다음에 조금 가져다드릴게요.”

**번역 화면 / 한국어:** 『제가 쓰는 향신료가 있어요. 다음에 조금 가져다드릴게요.』

순덕이 몇 번이나 고개를 끄덕인다. 답을 기다리던 손이 어느새 포크를 향해 간다. 한 조각 더 먹는다.

### 4. 이만큼이면 얼마나?

수만도 무말랭이 접시를 가리킨다. 폰의 음성 입력을 누른다.

**수만 — 네팔어 발화의 뜻:** “할머니, 이건 어떻게 만드세요? 제가 하면 이 맛이 안 나요.”

순덕이 번역을 읽는다. 반찬통 챙길 때보다 훨씬 신이 난다. 의자를 당겨 제대로 앉는다.

**순덕** (반갑게 설명, 손바닥으로 무치는 동작을 하며, 끝↓): “불려서 물기를 꼭 짜야 돼. 양념부터 넣으면 안 돼.”

수만이 번역을 읽고 고개를 끄덕인다. 자기 반찬을 다시 맛본다. 이제 원인을 알 것 같은 표정.

한 번 더 입력을 누른다.

**수만 — 네팔어 발화의 뜻:** “간장은 얼마나 넣어요?”

순덕이 접시 크기를 보고 손가락으로 작은 원을 만든다.

**순덕** (당연하다는 듯, 손으로 양을 보이며, 끝↓): “이만큼.”

수만이 번역 화면을 본다. 다시 할머니 손을 본다. 눈썹이 조금 올라간다.

순덕이 이번엔 수만의 아차르를 가리키고 입력을 누른다.

**순덕** (확인하듯, 아까 맛본 접시를 짚으며, 끝↑): “그럼 네 양념은 얼마나 넣어?”

수만이 네팔어 번역을 읽는다. 이번엔 자기도 손가락을 모아 양을 보여 준다. 폰을 누른다.

**수만 — 네팔어 발화의 뜻:** “이 정도요. 맛 보면서.”

순덕이 한국어 번역과 수만 손을 번갈아 본다. 웃음이 터진다.

**순덕** (동료를 만난 웃음, 자기 손도 들어 보이며, 끝↓): “너도 그렇구나.”

수만이 말뜻은 다 모르지만 자기와 같은 모양의 손을 보고 웃는다. 서로의 음식을 한 번 더 맛본다.

### 5. 조금만 주세요

순덕이 포크를 내려놓고 빈 반찬통 쪽을 본다. 가장 큰 통 하나를 골라 식탁에 올린다.

수만이 통을 본다. 순덕은 태연하게 음성 입력을 누른다.

**순덕** (가볍게 부탁, 큰 통을 자기 앞에 두며, 끝↓): “이거 조금만 싸 줘. 집에 가서 먹게.”

수만이 번역을 읽는다. ‘조금’이라는 뜻을 확인하고 큰 통을 한 번 본다. 웃음을 참는다.

그러더니 식탁 옆에서 자기가 씻어 둔 큰 통을 하나 더 꺼낸다. 크기가 비슷하다. 무말랭이 접시 옆에 놓는다.

수만이 음성 입력을 누른다.

**수만 — 네팔어 발화의 뜻:** “저도 이것 조금만 더 주세요.”

순덕이 번역을 읽는다. 수만의 큰 통을 보고 자기 통을 본다.

잠깐 정적. 둘 다 웃음이 터진다.

**순덕** (유쾌하게, 수만의 빈 통을 받아 들며, 끝↓): “그래. 많이 줄게.”

수만도 할머니 통에 아차르를 넉넉히 담는다. 순덕이 이쯤이면 됐다고 손을 들지만, 수만은 한 번 더 얹는다. 순덕은 말리지 않고 뚜껑을 챙긴다.

### 6. 통은 다시 오간다

잠시 후. 순덕 앞에는 아차르를 담은 통. 수만의 빈 통은 순덕 장바구니에 들어 있다. 무말랭이를 채워다 주실 통이다.

순덕이 자기 쪽으로 와 있던 폰을 수만에게 돌려준다.

**순덕** (일어나며, 장바구니를 들고, 끝↓): “이따 갖다줄게.”

**수만** (밝게, 눈을 맞추며, 끝↓): “감사합니다.”

순덕이 장바구니를 챙기는데 수만이 살짝 손을 든다. 급히 번역 입력을 한 번 더 누른다.

**수만 — 네팔어 발화의 뜻:** “할머니, 만드는 날 저도 불러 주세요.”

순덕이 번역을 읽고 웃는다.

**순덕** (반갑게, 수만의 접시를 가리키며, 끝↓): “너도 이거 할 때 나 불러.”

수만이 번역을 확인한다. 크게 고개를 끄덕인다.

순덕이 돌아간다. 수만이 다시 식탁에 앉는다. 밥그릇에 밥이 조금 남았다. 무말랭이 마지막 한 조각을 얹어 먹는다.

닫힌 현관 쪽에서 할머니 목소리가 들린다.

**순덕** (문밖에서 챙기듯, 끝↑): “수만아, 통 더 큰 거 없어?”

수만이 빈 통을 넣어 두는 선반을 본다. 천천히 입꼬리가 올라간다.

끝.

## 5. 다음 제작 단계

- 사용자 검토 후 콘티는 그록봇 담당. 이전 v01은 보관하고 새 회차 기준은 v02.
- 핵심 장면: 무말랭이에 밥그릇 당기는 수만 / 아차르를 보고 앉는 순덕 / 번역을 번갈아 눌러 이야기 / 양을 손으로 가늠하는 두 사람 / 같은 크기의 큰 통 두 개.
- 실제 조리 장면은 이번 회차에서 생략. 이미 만든 음식을 맛보고 조리법을 묻는 장면 중심. 요리 외의 수만 일상도 유지.
- 토마톡 UI는 도입 단톡 요청과 식탁의 번역 대화로 분리. 번역 화면의 실제 입력·언어 전환 방식을 확인한 뒤 컷 설계. 외국어 원문 검수 필요.
- 네팔어 대사를 한국어 음성으로 연기시키지 않는다. 각본의 ‘발화의 뜻’은 독자용 번역이다.
- 반찬통은 깨끗한 음식용으로만 사용. 어댑터·단추·이름표·멸치 세 마리 설정은 이번 초안에 사용하지 않는다.
- 이미지·영상은 아직 생성하지 않음. GPT 기준 이미지와 콘티 확정 후, 명시 지시가 있을 때만 힉스필드 영상 진행.

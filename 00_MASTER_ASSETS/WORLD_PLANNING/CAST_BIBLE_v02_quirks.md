# 연남동 3층집 캐스트 바이블 v02 — 빅뱅이론식 "고정 결함" 정리

작성 2026-11-05. v01의 이름·나이·얼굴·키는 그대로. 바뀐 것은 **각 인물의 웃음 엔진을 하나로 못 박는 것**이다.
사용자 지시(2026-11-05): 준호 못 버리기 / 할머니 멀리서도 잘 들음 / 하영 아이돌 덕후인데 전교 1등 / 시우 가난한 대학생·알바 많음·하영이 할머니께 부탁해 싸게 월세 / 하오 중국 부잣집 아들·가장 큰 방 / 수만 기러기 아빠·부주방장·요리사 자부심·항상 조리복·가족 데려오는 게 꿈. 리아·미유 확정(2026-11-05 사용자): **리아 = 가족 투표**, **미유 = 사극체**. 대안 행은 폐기.

## 빅뱅이론에서 가져오는 규칙 4개
1. **결함은 하나, 절대 안 고쳐진다.** 셸던의 자리처럼. 시즌 내내 같은 결함이 다른 상황과 부딪힌다. 성장은 "결함을 인정하는 순간"까지만, 고치지는 않는다.
2. **결함마다 '규칙'이 있다.** 룸메이트 계약서처럼 말로 선언된 규칙(아래 표의 규칙 열). 관객이 규칙을 외우면, 규칙이 깨지는 순간이 웃음이다.
3. **한 화 = 결함 두 개의 충돌.** A의 결함이 B의 결함을 건드린다. 주인공 커플 + 1명이 기본 단위.
4. **반응 샷으로 한 번 더.** 말한 사람이 아니라 듣는 사람 얼굴. 각 인물의 "고정 반응 표정"을 아래에 적는다(스틸 라이브러리 기준).

## 방 배치 (2026-11-05 사용자 확정 "방 배치 그대로" → WORLD_PLAN_FINAL·PH_v03 반영)
- 3층: 앞방 리아, 뒷방 미유 (v01 그대로)
- 2층(세트 뒷벽 문 3개): **큰방 하오**, 중간방 수만, 작은방 시우(월세 가장 쌈, 하영 청탁)
- 준호 짐: 2화 각본대로 3층집 안에 쌓임. 제안 = **1층 계단 밑 창고**(세트 왼쪽 계단 아래). 상자가 거실로 흘러나오는 게 눈에 보여서 "못 버림" 결함이 매 화 배경에 깔린다.
- 할머니: 옆집 단독주택, 평상이 CCTV. 하영은 주말에 할머니 집.

## 결함 충돌표 (에피소드 씨앗)
| 충돌 | 씨앗 |
|---|---|
| 준호 못 버림 × 리아 가족 투표 | 어떤 상자를 버릴지 가족 22명이 투표. 결과: 전부 "keep"(엄마가 "추억은 소중해") → 준호 승리, 리아 분노 |
| 준호 못 버림 × 수만 요리 | 준호 상자에서 10년 된 라면 발견. 수만이 "먹을 수 있다"고 요리함 |
| 할머니 잘 들음 × 리아 가족 투표 | 리아가 할머니 흉을 가족방에 (영어로) 씀 → 할머니는 못 읽지만, 준호가 소리 내 번역하는 걸 들음 |
| 할머니 잘 들음 × 미유 사극체 | 미유의 사극체 혼잣말을 할머니가 진짜 사극인 줄 알고 TV 틀어 줌. 할머니 몸뻬를 미유가 당의로 수선 |
| 하영 전교 1등 × 시우 알바 | 시우 과제를 하영이 10분에 풀어 줌. 시우는 "동생 똑똑하네"로 끝 → 하영 좌절 |
| 하영 × 할머니 | 할머니가 시우 월세 비밀을 보청기 때문에 거실에서 큰소리로 말해 버림 |
| 하오 돈 감각 × 수만 자부심 | 하오가 수만 식당 음식을 "비싸게 사 먹겠다"고 해서 수만 자존심 폭발. 하오는 왜 화났는지 모름 |
| 하오 × 시우 | 같은 2층, 큰방 vs 작은방. 하오가 "방 바꿔 줄게, 돈은 됐어" → 시우 자존심 |
| 수만 기러기 × 리아 가족 | 수만 아이 생일 영상통화에 리아 가족 22명이 난입해 축하 |
| 미유 × 하영 | 하영이 아이돌 무대 의상을 미유에게 주문 → 미유가 사극 스타일로 만들어 옴. 하영 "이건 콘서트지 궁중 잔치가 아니야" |
| 미유 × 하오 | 하오가 미유의 한복 작업을 몰래 찍어 올림 → 터짐 → 미유 "그대, 허락은 구하였소?" |

## 러닝 개그 (시즌 내내 반복)
- 준호: "오빠, 그거 아직도 써?" → "쓸 데가 있어."
- 할머니: 문 반만 열고 "다 들었다."
- 리아: "잠깐만, 가족한테 물어볼게." (폰 띠링 22번)
- 하영: 문제 해결 후 "헐, 이것도 몰라?" 하고 사라짐 (아이돌 덕후는 하영 혼자. 미유는 덕후 아님)
- 시우: 유니폼 바뀔 때마다 하오가 "오늘은 어디?"
- 하오: "그냥 내가 낼게" → 전원 침묵
- 수만: "일단 먹고." 음식 등장 효과음
- 미유: 번역기가 사극체를 셰익스피어 영어로 바꿔 리아 가족이 감탄 / 누군가의 옷이 아침에 수선돼 있음("미유가 다녀갔다")

## 1화·2화에 바로 반영할 것
- 1화: 리아 결함(가족 투표)이 이미 척추. 준호 결함은 배경(상자)으로만 보이게 1컷 추가 추천(와이드에 계단 밑 상자).
- 2화: 준호 결함이 척추. 할머니 "보청기 끼니 너무 잘 들으시네" 대사가 이미 있으니 할머니 결함 선언 장면으로 쓴다.

# 연남동 3층집 3화 「오늘 못 와?」 — 각본 v03

사용자 확정 소재: 순덕 할머니가 함께 밥 먹도록 정한 공동 저녁 규칙. 불참자는 저녁값 부담. 글로벌 토마톡 단톡방에 할머니도 참여. 할머니는 억척스럽지만 사람들 먹이는 데는 돈을 아끼지 않는다. 주 2회·화목 8시는 제안값.

## 0. 로그라인

공동 저녁 메뉴를 정하려는 총무 하오. 모두 아무거나 먹겠다면서 조건을 붙이지만, 수만이 못 올 수도 있다는 메시지를 보내자 순식간에 소고기로 뜻이 모인다. 수만의 참석 선언에 다들 저렴한 메뉴로 바꾸지만, 뒤늦게 소고기를 두 손 가득 들고 온 할머니가 계산뿐이던 저녁을 진짜 공동 식사로 만든다.

## 1. 상황

- 목요일 저녁 7시 40분, 1층 공용 거실. 공동 저녁은 8시.
- 소파에 리아와 준호. 하오는 암체어에서 배달 메뉴를 보고, 미유는 소파 옆에서 스케치북을 덮는다. 수만은 가게 일을 마치고 오는 중. 순덕은 아직 밖에 있다. 소고기를 사 오는 중이라는 사실은 등장 전까지 보여 주지 않는다.
- 음식과 그릇은 아직 없다. 누구도 주방에서 요리하고 있지 않다.
- 준호는 공동 식사에 초대된 손님. 이번 불참 벌금 대상이 아니다. 시우·하영은 방 멤버지만 이번 식사 대상이 아니다.
- 하오는 지난주 공동 저녁에 빠져 식사비를 낸 적이 있다. 오늘은 직접 참석한다.
- 공지: 「화·목 저녁 8시, 같이 밥 먹기. 못 오는 사람은 그날 저녁값 내기. — 순덕」. 여러 명 불참·불가피한 사유 등 세부 규칙은 이번 편에서 만들지 않는다.
- 토마톡 단톡방 이름은 「연남동 3층집 🏠」. 준호 폰의 한국어 화면을 기준으로, 외국어 메시지는 한국어 번역 위·원문 아래. 한국어 메시지는 원문만 표시. 내 메시지만 연분홍.
- 리아 영어, 하오 중국어, 미유 일본어, 수만 네팔어, 순덕·준호 한국어. 본문의 채팅은 관객이 읽는 한국어 뜻이며 외국어 원문은 별도 UI 데이터에서 검수한다. 번역 오류를 웃음의 원인으로 삼지 않는다.
- 한국어가 아직 서툰 사람들이 함께 사는 집이다. 같은 거실에서도 복잡한 의견은 각자 편한 언어로 토마톡에 쓰고 번역을 읽는다. 메뉴 제안·조건·합의는 단톡에서 진행한다. 쉬운 한국어와 표정·손짓은 곁들이되 채팅을 불필요한 것으로 취급하지 않는다.

## 4. 씬 본문

### 1. 참석률 100퍼센트

저녁 거실. 하오는 배달 앱을 열었다가 토마톡으로 바꾼다.

**단톡 / 하오:** 『오늘 저녁 참석 확인할게요.』

**단톡 / 리아:** 『참석!』

**단톡 / 미유:** 『반드시 가겠소.』

리아는 바로 옆 소파, 미유는 스케치북을 무릎에 놓은 채 답장을 쓴다. 준호가 둘과 하오를 번갈아 본다.

**준호** (감탄, 리아 쪽으로 몸을 기울이며, 끝↑): “다들 밥은 꼭 같이 먹네?”

리아가 준호 폰의 상단 공지를 짚는다.

**폰 공지:** 『화·목 저녁 8시, 같이 밥 먹기. 못 오는 사람은 그날 저녁값 내기. — 순덕』

준호 눈썹이 올라간다. 리아는 아무렇지 않게 커피를 마신다.

**리아** (담담, 컵을 내리며, 끝↓): “지난주에 하오가 한 번 빠졌어.”

준호가 하오를 본다. 하오는 메뉴를 넘기는 척한다.

**준호** (조심스러운 호기심, 폰을 살짝 내리며, 끝↑): “얼마 나왔는데?”

**하오** (씁쓸, 손가락을 멈추며, 끝↓): “그날만 다들 고기를 먹더라고요.”

준호가 리아를 본다. 리아는 컵으로 입을 가린다. 미유는 스케치북을 다시 펼친다. 아무도 고기를 부정하지 않는다.

### 2. 아무거나의 조건

하오가 다시 단톡에 쓴다.

**단톡 / 하오:** 『메뉴는요?』

**단톡 / 리아:** 『아무거나!』

**단톡 / 미유:** 『여러분 뜻에 따르겠소.』

**단톡 / 수만:** 『나도 괜찮아.』

하오는 안심하고 치킨 사진을 단톡에 공유한다.

**단톡 / 하오:** 『그럼 치킨?』

리아가 사진을 눌러 보고 답한다. 미유도 번역을 읽고 자신의 언어로 답장을 쓴다.

**단톡 / 리아:** 『튀긴 거 말고.』

**단톡 / 미유:** 『닭은 오늘 내키지 않소.』

하오가 치킨 창을 닫고 피자 사진을 공유한다.

**단톡 / 하오:** 『피자는?』

**단톡 / 리아:** 『점심에 빵 먹었어.』

**단톡 / 미유:** 『저녁은 밥이 좋겠소.』

하오가 앞서 올라온 『아무거나!』와 『여러분 뜻에 따르겠소.』를 다시 읽는다. 탈락한 음식 사진 두 장을 번갈아 보다가 답장을 쓴다.

**단톡 / 하오:** 『그럼 먹고 싶은 걸 하나씩 써 주세요.』

리아가 번역을 읽고 생각한다. 손가락이 잠깐 멈췄다가 움직인다.

**단톡 / 리아:** 『둘이 정해. 나는 진짜 아무거나 괜찮아.』

하오가 고개를 들어 리아를 본다. 리아는 진심이라는 듯 웃으며 고개를 끄덕인다. 하오가 피자와 치킨 사진을 다시 본다. 준호가 번역된 답장을 읽고 웃음을 삼킨다.

### 3. 갑자기 만장일치

수만의 메시지가 도착한다.

**단톡 / 수만:** 『오늘 가게 일이 늦게 끝날 것 같아. 저녁 못 갈 수도 있어.』

하오의 눈이 메시지에서 상단 공지로 올라간다. 리아도 컵을 내려놓는다. 미유의 스케치북이 조용히 닫힌다.

하오가 배달 메뉴를 검색한다. 이번엔 소고기 사진.

**단톡 / 하오:** 『소고기 어때요?』

**단톡 / 리아:** 『좋아.』

**단톡 / 미유:** 『소고기로 뜻을 모으겠소.』

하오가 입꼬리를 올린다. 준호가 뒤늦게 셋의 폰을 보더니 리아에게 작은 목소리로 묻는다.

**준호** (순수하게 궁금, 리아 쪽으로 기울며, 끝↑): “고기 먹을 때는 빵 먹은 거 괜찮아?”

리아가 대답 대신 준호의 무릎을 가볍게 톡 친다. 준호가 즉시 입을 다문다.

수만의 답장.

**단톡 / 수만:** 『갈게.』

한 박자 뒤.

**단톡 / 수만:** 『꼭 갈게. 먼저 시키지 마.』

하오의 손가락이 소고기 주문 버튼 위에서 멈춘다. 리아는 커피를 다시 든다. 미유는 스케치북을 다시 편다.

### 4. 취향이 바뀌는 속도

하오가 장바구니의 소고기를 본다. 수량 옆 빼기 버튼에 손가락을 올린다.

**단톡 / 리아:** 『생각해 보니 저녁은 가볍게 먹고 싶어.』

**단톡 / 미유:** 『김밥도 밥이오.』

소고기가 장바구니에서 사라진다. 하오가 깊게 숨을 들이쉰다.

**단톡 / 하오:** 『아까는 소고기로 뜻을 모으셨잖아요.』

미유가 번역을 읽고 스케치북의 페이지를 넘긴다. 리아도 메시지를 확인한 뒤 준호 컵까지 챙겨 일어난다. 아무도 답하지 않는다.

하오가 김밥을 장바구니에 담는다. 아직 주문 버튼은 누르지 않았다.

**단톡 / 하오:** 『그럼 김밥으로 할게요.』

### 5. 소고기는 어디에

잠시 후. 수만이 거실에 이미 도착해 있다. 숨을 고르며 폰을 확인한다. 「소고기로 뜻을 모으겠소」 아래에 새로 올라온 「김밥으로 할게요」.

수만이 화면을 한 번 위로 올렸다가 내린다. 하오를 본다.

**수만** (어리둥절, 폰을 들어 보이며, 끝↑): “소고기는?”

하오가 배달 앱을 보며 답장을 쓴다.

**단톡 / 하오:** 『다 같이 가볍게 먹기로 했어요.』

수만이 번역을 읽는다. 리아를 본다. 리아는 빈 컵을 정리한다. 미유는 스케치북을 가방에 넣는다. 다들 갑자기 할 일이 생겼다.

수만이 천천히 답장을 쓴다.

**단톡 / 수만:** 『내가 온다고 해서?』

하오의 손가락이 멈춘다. 준호가 폰을 읽고 고개를 숙인다. 웃으면 안 될 것 같아서 입술을 깨문다.

그때 현관 쪽에서 할머니 목소리.

**순덕** (두 손이 무거워 재촉, 문밖에서, 끝↑): “준호야! 이것 좀 받아!”

### 6. 먹는 데는 안 아낀다

현관 쪽 새 장면. 순덕 할머니가 이미 문 안에 서 있다. 양손에 묵직한 장바구니. 위로 소고기 포장들이 보인다. 준호가 한쪽을 받아 들고 무게에 팔을 한 번 고쳐 든다.

**순덕** (식탁을 살피며, 숨을 돌리고, 끝↑): “아직 저녁 안 먹었어?”

하오가 주문 직전의 폰을 내린다. 전원이 고개를 끄덕인다.

순덕이 소고기 포장을 들어 보인다.

**순덕** (반갑게, 고기를 식탁에 놓으며, 끝↓): “그럼 이거 같이 구워 먹자.”

다른 쪽 장바구니에서도 고기가 나온다. 한 팩 더, 또 한 팩. 미유가 스케치북을 치워 자리를 만든다. 리아가 다가와 장바구니를 받아 준다.

수만이 소고기를 보다가 자기 폰의 김밥 메시지를 본다. 입꼬리가 올라간다.

**준호** (양에 놀라, 포장들을 세다가, 끝↑): “할머니, 뭘 이렇게 많이 샀어?”

**순덕** (당연하다는 듯, 마지막 팩을 놓으며, 끝↓): “먹다가 모자라면 안 되잖아.”

하오가 폰을 계산기처럼 들었다가 조심스럽게 묻는다.

**하오** (총무의 습관, 고기를 가리키며, 끝↑): “이건 얼마씩 내요?”

순덕이 하오를 쳐다본다.

**순덕** (툭, 빈 접시를 건네며, 끝↓): “됐어. 접시나 가져와.”

하오가 얼른 폰을 넣고 접시를 받는다.

준호는 장바구니를 접으려다 바닥에 남은 고기 한 팩을 발견한다. 할머니를 본다. 할머니는 그 팩도 꺼내 식탁에 놓는다.

**준호** (작게 웃으며, 빈 장바구니를 접고, 끝↓): “먹는 데는 진짜 안 아끼네.”

**순덕** (단호하지만 정 있게, 식탁을 정리하며, 끝↓): “먹는 건 잘 먹어야지.”

잠시 후. 식탁에 전원이 앉아 있다. 전기 그릴 위에서 고기가 익는다. 준호가 집게를 들고 굽는다. 할머니는 리아와 수만 접시부터 챙긴다. 수만을 주방 담당으로 몰지 않는다.

하오가 고기를 먹으려는데 폰 알림이 한 번 울린다.

**단톡 / 수만:** 『나 오늘 오길 잘했네.』

하오가 수만을 본다. 수만이 웃으며 고기를 먹는다. 하오도 웃고 자기 앞의 고기를 집는다.

리아가 폰에 짧게 답한다.

**단톡 / 리아:** 『할머니 다음에도 오세요 ❤️』

순덕이 폰을 읽는다. 고기 굽던 준호를 한 번 본다.

**순덕** (흐뭇한 잔소리, 준호 접시를 밀어 주며, 끝↓): “너도 먹어. 굽기만 하지 말고.”

준호가 웃으며 얼른 집게를 돌린다. 리아가 옆에서 그의 접시에 고기 한 점을 놓는다.

다 같이 먹는 식탁. 빈 장바구니는 의자 옆에 접혀 있다.

끝.

## 5. 다음 제작 단계

- 사용자 각본 검토 후 콘티·컷 리스트 작성. 이 초안은 최종 확정 아님.
- UI는 별도 렌더 후 합성. 영상 AI에 글자·말풍선을 생성시키지 않는다.
- UI 필요 상태: 공지·참석 / 메뉴 거절 / 수만 불참 가능·소고기 합의 / 참석 번복·김밥 / 수만 도착·「내가 온다고 해서?」 / 소고기 식사·수만과 리아의 메시지. 할머니 도착과 양손 소고기 공개는 실사 콘티 장면으로 따로 준비.

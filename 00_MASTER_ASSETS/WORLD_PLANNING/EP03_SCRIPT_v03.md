# 연남동 3층집 3화 「오늘 못 와?」 — 각본 v03

STATUS: DRAFT / 사용자 검토 전. 기존 v01·v02 가스비 이야기를 대체하는 새 초안.
사용자 확정 소재: 순덕 할머니가 함께 밥 먹도록 정한 공동 저녁 규칙. 불참자는 저녁값 부담. 글로벌 토마톡 단톡방에 할머니도 참여. 주 2회·화목 8시는 제안값.

## 0. 로그라인

공동 저녁 메뉴를 정하려는 총무 하오. 모두 아무거나 먹겠다면서 조건을 붙이지만, 수만이 못 올 수도 있다는 메시지를 보내자 순식간에 소고기로 뜻이 모인다. 저녁값을 피하려는 수만의 참석 선언으로 합의는 다시 무너진다.

## 1. 상황

- 목요일 저녁 7시 40분, 1층 공용 거실. 공동 저녁은 8시.
- 소파에 리아와 준호. 하오는 암체어에서 배달 메뉴를 보고, 미유는 소파 옆에서 스케치북을 덮는다. 수만은 가게 일을 마치고 오는 중. 순덕은 옆집에서 반찬을 챙긴다.
- 음식과 그릇은 아직 없다. 누구도 주방에서 요리하고 있지 않다.
- 준호는 공동 식사에 초대된 손님. 이번 불참 벌금 대상이 아니다. 시우·하영은 방 멤버지만 이번 식사 대상이 아니다.
- 하오는 지난주 공동 저녁에 빠져 식사비를 낸 적이 있다. 오늘은 직접 참석한다.
- 공지: 「화·목 저녁 8시, 같이 밥 먹기. 못 오는 사람은 그날 저녁값 내기. — 순덕」. 여러 명 불참·불가피한 사유 등 세부 규칙은 이번 편에서 만들지 않는다.
- 토마톡 단톡방 이름은 「연남동 3층집 🏠」. 준호 폰의 한국어 화면을 기준으로, 외국어 메시지는 한국어 번역 위·원문 아래. 한국어 메시지는 원문만 표시. 내 메시지만 연분홍.
- 리아 영어, 하오 중국어, 미유 일본어, 수만 네팔어, 순덕·준호 한국어. 본문의 채팅은 관객이 읽는 한국어 뜻이며 외국어 원문은 별도 UI 데이터에서 검수한다. 번역 오류를 웃음의 원인으로 삼지 않는다.

## 2. 인물 카드

| 인물 | 원하는 것 | 두려운 것 | 시작 → 끝 |
|---|---|---|---|
| 하오 | 오늘 메뉴를 빨리 정하기 | 지난주처럼 자기 돈으로 고기 먹이기 | 총무의 의욕 → 답답함 → 소고기 기대 → 체념 |
| 리아 | 좋아하는 저녁을 부담 없이 먹기 | 싫은 메뉴로 정해지는 것 | 느긋함 → 조건 제시 → 소고기에 적극 동의 → 조용한 후퇴 |
| 준호 | 리아와 같이 저녁 먹기 | 선택을 잘못해 일이 꼬이는 것 | 부러운 손님 → 규칙 이해 → 상황을 따라가다 민망 |
| 미유 | 취향에 맞는 공동 식사 | 자기 의견이 빠지는 것 | 점잖은 양보 → 소고기에 단호 → 메뉴 철회 |
| 수만 | 일 마치고 함께 먹기 | 불참 식사비가 커지는 것 | 일정 걱정 → 소고기 메시지에 다급 → 도착 후 어이없음 |
| 순덕 | 사람들이 한 상에 앉아 먹기 | 각자 방에서 끼니 때우는 것 | 반찬 챙김 → 빈자리 발견 → 사람부터 챙김 |

| 2 | 아무거나라는 답변 뒤 메뉴마다 거절 | 하오 의욕 → 답답함 | 메뉴를 넘기고 같은 거실 사람들을 봄 | 각자 조건이 있다 |
| 3 | 수만이 늦어 못 올 수 있다고 보냄 | 모두 갑자기 적극적 | 폰을 다시 들고 소고기 합의 | 누가 내느냐에 따라 취향이 바뀐다 |
| 4 | 수만의 참석 확답 | 기대 → 민망 | 고기 메뉴와 메시지를 슬쩍 거둠 | 수만도 지난 규칙을 안다 |

| 6 | 할머니는 빈자리부터 챙김 | 계산 → 머쓱함 | 반찬을 놓고 수만 자리를 마련 | 규칙의 원래 목적은 같이 먹기 |
| 7 | 수만 도착, 소고기 대신 김밥 | 안도 → 황당한 웃음 | 메뉴 확인, 전원이 시선 회피 | 같은 멤버가 내 돈이면 달라진다 |

## 4. 씬 본문

### 1. 참석률 100퍼센트

저녁 거실. 하오는 배달 앱을 열었다가 토마톡으로 바꾼다.

**단톡 / 하오:** 『오늘 저녁 참석 확인할게요.』

**단톡 / 리아:** 『참석!』

**단톡 / 미유:** 『반드시 가겠소.』

리아는 바로 옆 소파, 미유는 스케치북을 무릎에 놓은 채 답장을 쓴다. 준호가 둘과 하오를 번갈아 본다.

**준호** (감탄, 리아 쪽으로 몸을 기울이며, 끝↑): “다들 밥은 꼭 같이 먹네?”

리아가 준호 폰의 상단 공지를 짚는다.

**폰 공지:** 『화·목 저녁 8시, 같이 밥 먹기. 못 오는 사람은 그날 저녁값 내기. — 순덕』

준호 눈썹이 올라간다. 리아는 아무렇지 않게 커피를 마신다.

**리아** (담담, 컵을 내리며, 끝↓): “지난주에 하오가 한 번 빠졌어.”

준호가 하오를 본다. 하오는 메뉴를 넘기는 척한다.

**준호** (조심스러운 호기심, 폰을 살짝 내리며, 끝↑): “얼마 나왔는데?”

**하오** (씁쓸, 손가락을 멈추며, 끝↓): “그날만 다들 고기를 먹더라고요.”

준호가 리아를 본다. 리아는 컵으로 입을 가린다. 미유는 스케치북을 다시 펼친다. 아무도 고기를 부정하지 않는다.

### 2. 아무거나의 조건

하오가 다시 단톡에 쓴다.

**단톡 / 하오:** 『메뉴는요?』

**단톡 / 리아:** 『아무거나!』

**단톡 / 미유:** 『여러분 뜻에 따르겠소.』

**단톡 / 수만:** 『나도 괜찮아.』

하오는 안심하고 치킨 사진을 연다.

**하오** (가볍게 제안, 화면을 들어 보이며, 끝↑): “그럼 치킨?”

리아는 하오를 보지 않고 폰에 답한다.

**단톡 / 리아:** 『튀긴 거 말고.』

**단톡 / 미유:** 『닭은 오늘 내키지 않소.』

하오가 치킨 창을 닫는다. 피자 사진.

**하오** (다시 제안, 폰을 넘기며, 끝↑): “피자는?”

**단톡 / 리아:** 『점심에 빵 먹었어.』

**단톡 / 미유:** 『저녁은 밥이 좋겠소.』

하오가 폰에서 고개를 든다. 둘 다 손 뻗으면 닿을 거리다.

**하오** (참다가 부탁, 둘을 번갈아 보며, 끝↑): “그냥 말로 하면 안 돼요?”

리아가 하오와 눈을 맞춘다. 잠깐 정적. 다시 폰을 내려다본다.

**단톡 / 리아:** 『왜 화났어?』

하오가 입을 열었다 닫는다. 준호가 웃음을 삼키며 자기 폰을 엎는다.

### 3. 갑자기 만장일치

수만의 메시지가 도착한다.

**단톡 / 수만:** 『오늘 가게 일이 늦게 끝날 것 같아. 저녁 못 갈 수도 있어.』

하오의 눈이 메시지에서 상단 공지로 올라간다. 리아도 컵을 내려놓는다. 미유의 스케치북이 조용히 닫힌다.

하오가 배달 메뉴를 검색한다. 이번엔 소고기 사진.

**단톡 / 하오:** 『소고기 어때요?』

**단톡 / 리아:** 『좋아.』

**단톡 / 미유:** 『소고기로 뜻을 모으겠소.』

하오가 입꼬리를 올린다. 준호가 뒤늦게 셋의 폰을 보더니 리아에게 작은 목소리로 묻는다.

**준호** (순수하게 궁금, 리아 쪽으로 기울며, 끝↑): “고기 먹을 때는 빵 먹은 거 괜찮아?”

리아가 대답 대신 준호의 무릎을 가볍게 톡 친다. 준호가 즉시 입을 다문다.

수만의 답장.

**단톡 / 수만:** 『갈게.』

한 박자 뒤.

**단톡 / 수만:** 『꼭 갈게. 먼저 시키지 마.』

하오의 손가락이 소고기 주문 버튼 위에서 멈춘다. 리아는 커피를 다시 든다. 미유는 스케치북을 다시 편다.

### 4. 취향이 바뀌는 속도

하오가 장바구니의 소고기를 본다. 수량 옆 빼기 버튼에 손가락을 올린다.

**단톡 / 리아:** 『생각해 보니 저녁은 가볍게 먹고 싶어.』

**단톡 / 미유:** 『김밥도 밥이오.』

소고기가 장바구니에서 사라진다. 하오가 깊게 숨을 들이쉰다.

**하오** (체념, 빈 장바구니를 보며, 끝↓): “아까는 소고기로 뜻을 모으셨잖아요.”

미유가 스케치북의 페이지를 넘긴다. 리아는 준호 컵까지 챙겨 일어난다. 아무도 답하지 않는다.

### 5. 할머니가 정한 이유

현관. 순덕 할머니가 반찬통을 들고 이미 문 안에 서 있다.

빈 식탁을 본다. 하오의 폰에만 메뉴 사진이 가득하다.

**순덕** (의아함, 반찬통을 놓으며, 끝↑): “여태 안 먹었어?”

**하오** (지친 보고, 폰을 내리며, 끝↓): “메뉴 정하고 있어요.”

순덕은 메뉴보다 빈자리를 먼저 본다.

**순덕** (찾는 마음, 거실을 둘러보며, 끝↑): “수만이는?”

**리아** (알리듯, 식탁 쪽으로 컵을 옮기며, 끝↓): “가게 끝나고 온대요.”

순덕이 수만 자리에도 젓가락을 놓는다.

**순덕** (당연하다는 듯, 의자를 빼며, 끝↓): “그럼 걔 오면 먹자.”

리아가 잠깐 수만의 자리를 본다. 하오는 단톡에 짧게 쓴다.

**단톡 / 하오:** 『기다릴게요. 천천히 와요.』

순덕의 폰에도 같은 메시지가 뜬다. 안경을 살짝 올리고 답한다.

**단톡 / 순덕 할머니:** 『오는 길에 뛰지 마라.』

준호가 할머니 쪽을 보고 웃는다. 할머니는 반찬통 뚜껑을 열느라 못 본다.

### 6. 소고기는 어디에

잠시 후. 식탁 위에 배달 김밥과 할머니 반찬. 수만이 식탁 앞에 앉아 있다. 이동은 생략한다.

수만이 김밥을 본다. 폰의 소고기 메시지를 본다. 다시 김밥을 본다.

**수만** (어리둥절, 젓가락을 든 채, 끝↑): “소고기는?”

하오는 김밥 단면을 유심히 본다. 리아는 반찬통을 수만 쪽으로 민다. 미유는 이미 한 입 먹어서 말을 못 한다.

준호만 설명해 보려 손가락을 든다.

**준호** (도와주려다 스스로 막힘, 손가락을 내리며, 끝 흐림): “아, 그게… 다 같이 내니까…”

리아가 준호를 본다. 준호는 김밥을 한입에 넣는다.

수만이 천천히 하오를 본다. 하오는 눈을 피하며 김밥을 먹는다.

수만이 폰을 들어 단톡에 쓴다.

**단톡 / 수만:** 『다음에 하오 없는 날 소고기 먹자.』

하오가 급하게 김밥을 삼킨다. 바로 답장.

**단톡 / 하오:** 『나 이제 안 빠져요.』

수만이 웃는다. 리아도 고개를 숙이고 웃는다. 순덕은 폰을 보다가 함께 앉은 사람들을 본다. 만족스럽게 수만 밥 쪽으로 반찬을 한 번 더 밀어 준다.

**순덕** (흐뭇, 자기 젓가락을 들며, 끝↓): “거봐. 같이 먹으니까 좋지?”

하오가 김밥을 든 채 할머니를 본다. 다른 사람들은 이미 먹고 있다.

하오도 결국 웃으며 김밥을 먹는다.

끝.

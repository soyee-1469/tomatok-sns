## 2. 캐릭터·세트·이미지 고정

**[확정규칙]**
- 처음부터 **네이티브 세로 9:16**으로 만든다. 가로 생성 후 잘라 맞추는 방식을 기본으로 삼지 않는다.
- 확정 마스터 얼굴은 바꾸지 않는다. 의상 변경은 컷리스트에 명시한 승인된 의상만 적용한다. 실제 배우 닮게 만들지 않는다.
- 스타일 가이드는 **정면 얼굴을 별도 이미지로 크게**, 몸 전·후면은 **얼굴 없이 목부터 아래만** 만든다.
- ChatGPT 이미지는 **한 이미지마다 새 채팅**을 열고 기준 이미지를 첨부한다.
- 수정사항을 모아 **좋은 원본에서 한 번에 수정**한다. 불량 수정본을 계속 다시 넣는 연쇄 편집은 금지한다. 실제로 세트 계단 구조가 이 과정에서 무너졌다.
- 처음부터 깨끗하고 선명한 이미지를 요구한다. 프롬프트에 `film grain`, `skin pores`를 넣지 않는다.
- 세트는 고르고 부드러운 실내광을 유지하고 햇빛 유입을 금지한다.

**[스킬 확인 + 실무제안]** 레퍼런스는 마스터 얼굴 → 확정 세트/장면 → 색감 순서로 구분한다. 톤 참고는 색·조명만 따르고 그 사진의 얼굴·옷·장소는 베끼지 않게 명시한다. 모든 인물 이미지·영상 요청에 마스터 얼굴을 참조하고, 영상 시작 프레임은 얼굴 검수된 확정 정지 컷을 사용한다.

장면 연속성 참조에는 확정된 컷을 쓸 수 있지만, 구조나 얼굴이 망가진 수정본을 새 기준으로 승격하지 않는다. 승인된 원본과 비교해 얼굴·헤어·의상·문·계단·가구·소품이 달라지면 먼저 정지 컷을 고친다.

## 3. 세로 화면 안전영역

**[스킬 확인]** sns-shorts-safe-zone의 1080×1920 작업 가이드다. 플랫폼 공식 불변 규격이 아니라 배치용 시작값이며, 최종 앱 UI 미리보기에서 확인한다.

| 가장자리 | 비워 둘 권장 영역 |
|---|---|
| 위 | 약 180–220px |
| 아래 | 약 300–350px |
| 오른쪽 | 약 160–200px |
| 왼쪽 | 약 80–100px |

- 얼굴은 중앙보다 살짝 위, 핵심 손동작·폰은 중앙 안전영역에 둔다. 오른쪽 버튼 영역을 피한다.
- 자막은 하단에서 약 400–500px 위, 최대 두 줄을 작업 기준으로 삼는다.
- 폰은 읽을 수 있는 화면 글자 없이 생성하고 실제 메시지·앱 UI는 편집에서 합성한다.
- 검수 가이드 오버레이 예: 위 200 / 아래 350 / 오른쪽 180 / 왼쪽 90px. 다른 해상도라면 비례 적용하되 실제 플랫폼 화면에서 다시 검수한다.
- 이미지 업스케일로 디테일을 덧붙이는 대신 원본을 선명하게 만들고, 필요 시 최종 영상 단계에서 화질 보정을 검토한다.

## 4. 연기·영상: 감정 이름 대신 보이는 행동

**[원문조언]** ‘놀람/짜증/슬픔’만 쓰지 말고 눈·눈썹·입·고개·손이 **언제 무엇을 하는지** 적는다. 한 비트에 전부 쓰지 말고 필요한 두세 부위만 고른다.

| 부위 | 관찰 가능한 지시 예 |
|---|---|
| 눈 | 폰에서 상대 얼굴로 시선 이동, 한 번 느리게 깜빡임 |
| 눈썹 | 올라감, 미간 쪽으로 모임 |
| 입 | 입꼬리가 조금 내려감, 입을 다문 채 유지 |
| 고개 | 상대 쪽으로 돌림, 턱을 듦 |
| 손 | 폰 쥔 손이 멈춤, 손등 문지르기 |

**[원문조언]**
- CHARACTERS에 인물마다 `Rule:`을 쓴다. 금지만 쓰지 않고 대신 움직일 부위를 지정한다. 예: 입은 다문 채 눈만 상대에게 이동.
- 샷은 **촉발(소리·대사·동작) → 반응(시선·신체 변화) → 회복(다음 행동)**으로 나누고 초를 붙인다.
- 긴 대사는 마디마다 동작을 연결하고 필요하면 듣는 사람 컷으로 나눈다. 클로즈업일수록 움직임을 줄인다.
- 펀치라인 뒤 **0.5초 이상 반응 여백**, 대사는 **초당 6음절 이하**를 권장 시작점으로 사용한다. 이는 원문 제작진의 작업 기준이지 모든 모델·언어·장면의 절대 규격이 아니다. 실제 발화와 템포를 보고 조정한다.
- 고정 표정과 코미디 멈춤을 구분한다. 멈춤에는 이유·정해진 길이·끝나는 행동이 있어야 한다.
- 대사에는 화자·큰따옴표·발화 시간 창을 쓴다. 사투리·영어 약자·숫자는 원하는 발음대로 쓴다.
- 말투는 형용사만 두지 않고 호흡·쉼·속도·동작과 연결한다. 효과음도 화면 동작과 같은 초에 배치한다.
- `Only the N lines in SHOTS, each spoken once at its time; no added words.`처럼 대사 수를 명시한다. 무대사 비트의 입 상태와 화면 밖 화자도 구분한다.
- 원문은 대사를 생성 프롬프트에 넣고 모델 생성 음성을 활용하는 방식을 제안한다. 도구가 해당 기능을 지원하는지는 실행 전 확인하고, 지원한다고 가정하지 않는다. 결과는 귀와 받아쓰기로 검수한다.

## 5. 편집 → 최종 검수

**[기존 워크플로]** Mac Claude는 기획·프롬프트·코드 반복 작업, ChatGPT는 이미지, 영상 도구는 클립, 편집 앱은 컷 연결·자막·폰 UI·효과음 마무리를 담당한다. 검정고무신 작업의 Seedance/CapCut 조합은 과거 선택이지 필수 도구 규격이 아니다.

**[실무제안]**
1. 확정 정지 컷부터 나란히 비교한다. 마스터 얼굴 크롭과 결과 얼굴 크롭을 비교하고 불일치는 영상화 전에 해결한다.
2. 클립은 반응이 읽히는 위치에서 연결한다. 자동으로 대사 끝에 잘라 표정·정적을 없애지 않는다.
3. 폰 UI·자막은 편집에서 합성한다. 번역·원문이 작은 화면에서도 읽히는지 확인한다.
4. 발화 내용·립싱크·효과음 시점·대사 밀림을 듣고 본다. 밀린 부분은 무조건 음성을 잘라내지 말고 발화 창이나 컷 구성을 수정한다.
5. 소리 없이도 상황·반응이 읽히는지, 소리만 들어도 화자와 발화가 맞는지 각각 확인한다.
6. 확정본·프롬프트·참고 파일을 함께 보관한다. 컷 ID와 버전으로 파일을 연결하고 승인본은 덮어쓰지 않는다.

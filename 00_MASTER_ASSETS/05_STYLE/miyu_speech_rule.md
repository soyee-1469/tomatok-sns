# 미유 말투 규칙 — 사극체 (2026-11-05 확정)

**설정.** 미유(24, 오사카)는 패션 유학생. 사극 의상(한복·당의·곤룡포)에 반해 한국에 왔고, 한국어를 사극 드라마로 배웠다. 아이돌 덕후가 아니다(그건 하영). 그래서 평소엔 조용하지만 입을 열면 조선시대 사극 대사처럼 말한다. 본인은 그게 "정중한 한국어"인 줄 안다. 아무도 고쳐 주지 않는다(고쳐 주면 결함이 사라지므로).

## 사극체란
사극(역사 드라마)에서 쓰는 옛 말투. 어미와 호칭이 다르다.
| 보통 말 | 사극체 |
|---|---|
| 밥 먹었어? | 식사는 하셨소? |
| 왜 그래? | 어찌 그러시오? |
| 너 | 그대 |
| 알겠어 | 알겠사옵니다 / 그리하겠소 |
| 안 돼 | 아니 되오 |
| 진짜? | 참말이오? |
| 나 간다 | 소인, 이만 물러가겠소 |
| 준호 오빠 | 준호 도령 |
| 할머니 | 어르신 / 마님 |
| 리아 언니 | 리아 낭자 |

## 규칙
1. 어미는 **-오 / -소 / -사옵니다 / -느냐** 중 하나. 반말·요체 금지. 길이는 짧게(한 줄 12자 안팎).
2. 호칭 고정: 준호 도령, 리아 낭자, 수만 대감(요리사라 존경), 하오 서방, 하영 아씨, 시우 선비, 할머니 마님.
3. 옷감·바느질 모드에서는 말이 빨라지고 전문용어(원단, 시접, 깃)가 섞이지만 어미는 여전히 사극체: "이 깃은 시접이 모자라오."
4. 감정이 격해질수록 더 옛말이 된다. 화나면 "네 이놈" 대신 "그대, 선을 넘었소."
5. 번역 러닝개그: 토마톡이 사극체를 **셰익스피어풍 영어**로 번역한다. "식사는 하셨소?" → "Hast thou dined?" 리아 가족이 "Miyu는 시인이냐"고 감탄 → 리아는 설명을 포기함. 미유 폰 EN 뷰를 만들 때 번역문은 thou/thee/hath 를 쓴다.
6. 일본어는 혼잣말 한 단어만("え?", "やば"). 문장으로는 안 쓴다.

## 대사 예시 (1·2화 삽입 후보)
- 리아가 가족 투표 기다릴 때: "낭자, 스물두 명의 뜻을 어찌 다 기다리시오."
- 준호 상자를 보고: "도령, 이 상자들은 전부 추억이오, 쓰레기요?"
- 할머니 반찬을 받고: "마님의 은혜, 소인 잊지 않겠사옵니다." → 할머니: "얘는 말을 왜 이렇게 해?" → 하영: "할머니, 드라마 때문이야."
- 하영 무대 의상 주문을 받고: "아씨, 무대 의상이라 하였소? 당의로 하겠소." → 하영 "콘서트라고!"

## 쓰지 않는 것
- 오타쿠 과장 표현("~데스", "~입니다만"), 일본어 억양 흉내 금지. 미유의 웃음은 발음이 아니라 **말투의 시대착오**에서 나온다.

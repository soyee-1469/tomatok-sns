# 리아 언어 규칙 (2026-11-05 사용자 확정)

설정: 필리핀 엄마 + 미국 아빠 혼혈, 영어가 더 편함. 한국에 살고 준호와는 한국어. 토마톡 가족방에는 영어로 쓴다. **"쓰는 건 영어, 말하는 건 한국어."**

## 말할 때
1. 뼈대는 한국어. 한 줄에 영어 단어 **하나**까지(명사·감탄사·끝말). 예: "오빠, still? 그거 아직도 써?" / "이모지 cute하대." / "OK OK, 알겠어." / "Sana all~"
2. 감정 폭발 때만 영어 문장 통째. 자막은 "(영어로, 빠르게)"만 달고 단어는 적지 않는다. 시청자도 준호처럼 못 알아들어야 한다.
3. 순덕 할머니 앞에서는 영어 단어 0개. 평소 섞던 사람이 할머니 앞에서만 또박또박 한국어가 되는 낙차가 웃음.
4. 타갈로그어는 입으로 절대 안 낸다. 말풍선 글자로만(발음 사고 방지).

## 목소리 노트 (Kling 프롬프트용)
- 필리핀 영어 억양이 살짝 묻은 한국어. 리듬이 영어식으로 올라감. 밝고 장난스러운 톤.
- 영어 단어가 나오는 순간 발음이 자연스럽게 영어로 전환.
- 영어 프롬프트 예: `Korean with a light Filipino-English accent, rising English-like rhythm, bright and playful; the single English word is pronounced natively in English`.

## 생성 주의
- 한 줄에 영어 단어 하나 이상 넣지 않는다(언어 전환 지점이 Kling 사고 지점. EP01 투샷 말레이어 사례).
- 첫 에피소드 생성 전에 혼합 대사 1줄만 테스트 클립(std 3s, 6cr)으로 뽑아 whisper로 언어 확인.

## 다른 사람
- 준호: 한국어만. 영어는 "오케이, 땡큐, 쏘리" 수준의 한국어 발음 영어.
- 순덕: 한국어만. 외국인 이름을 한국식으로 부름.
- 수만: 주방 한국어(반말·존댓말 혼합). 네팔어는 입으로 안 냄.
- 하오: 유창한 한국어. 당황하면 "그건 내가 알려줄게요… 아 잠깐, 검색 좀."

## 테스트 결과로 좁힌 규칙 (2026-11-05 테스트 클립 2회)
- 문장 중간에 끼운 영어 단어("오빠, still? 그거…")는 Kling이 두 번 다 한국어식으로 뭉갰다(whisper: "시대요", "아스트요"). **영어는 문장 중간에 끼우지 않는다.**
- 영어는 **독립된 한 단어 문장**으로만: "Seriously." "No." "OK." "Sana all~" — 이 형태는 E2_03·E2_08에서 정확히 나왔다.
- 따라서 1화 첫 줄은 "오빠, 그거 아직도 써?"로 확정. 리아의 혼합어 느낌은 "OK OK." "Seriously." 같은 독립 단어로 낸다.
- 준호 개그 톤 테스트("첫인상이잖아! 22명이면 첫인상이 22개야.")는 whisper 정확, 톤 확인은 사용자 청취.

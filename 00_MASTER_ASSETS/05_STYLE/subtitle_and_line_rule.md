# 자막·대사표 규칙 (2026-10-29 사용자 지침)

## 대사 한 줄에는 항상 "감정 + 말투 + 끝음"을 같이 적는다
- 형식: `화자 (감정, 말투, 끝음↑/↓) "대사"`
- 예: `남 (얼떨떨, 말끝 흐림, 끝음↑) "누가… 또 들어오시네?"`
- 예: `남 (놀람, 가볍게) "응? 가족이 엄청 많네?"`
- 예: `여 (밝게, 놀리듯) "그래도 바로 번역돼서 다행이다~"`
- 이유: 같은 글자라도 짜증/당황/얼떨떨이 Kling 발화에 그대로 반영된다. 감정이 없으면 모델이 심각한 톤으로 기울고 재생성 비용이 든다.

## 적용 위치
1. 대본(`script_vNN.md`) 대사 칸
2. 자막 목록(`tools/subtitles_pass.py`의 LINES, 세 번째 값 = 연기 메모)
3. Kling 프롬프트 DIALOGUE/PERFORMANCE 문단 (영어로 번역해서 넣는다: dazed, flustered, rising intonation at the end 등)

## 화면 자막 자체에는 감정 표기를 쓰지 않는다
- 화면에는 대사 글자만. 감정·끝음 메모는 제작용 메타데이터.
- 자막 글자는 실제 발화 기준(음성 인식 확인본)으로 맞춘다. 대본과 다르게 말했으면 자막이 발화를 따른다.

## 끝음 표기
- `끝음↑` = 의문·되묻기·얼떨떨 ("들어오시네?")
- `끝음↓` = 단정·체념 ("하루 걸리겠는걸.")
- `말끝 흐림` = "…"로 표기하고 프롬프트에 trailing off 명시
